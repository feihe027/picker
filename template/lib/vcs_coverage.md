**2. How pytest saves coverage**

VCS is loaded as a shared library into the host Python process, so coverage
behaves differently from a standalone `simv`:

- **Only `$finish` commits the `.vdb`.** In this in-process mode `$cm_dump` and
  `vpi_control(vpiCoverageSave)` run but do NOT flush coverage — verified on real
  VCS. Coverage is written exactly once, by the terminating `$finish`.
- **`$finish` is deferred to process exit.** The Python shared runtime (default
  under pytest) registers an `atexit` hook and makes `dut.Finish()` a no-op while
  shared; the real `$finish` fires only when the interpreter exits, after pytest
  has finished reporting. Call `dut.Shutdown()` to force it early.
- **One process = one cumulative `.vdb`.** Coverage accumulates across every test
  case — and every test file — that runs in the same pytest process against this
  DUT (it is one continuous simulation). More cases only grow the union; it never
  resets.
- **No per-case split in one process.** You cannot get a separate `.vdb` per test
  case/file within a single process (only the one `$finish` at exit commits). For
  per-file coverage, run each file in its own process (`pytest-forked`, or
  separate `pytest` invocations) so each produces its own `.vdb`, then merge with
  `urg -dir a.vdb -dir b.vdb ...`.
- **Different DUTs need separate processes.** One process can host only one VCS
  `simv`, so suites for different DUTs must not share a process.

**3. Generating the report**

After the test process has exited (so the `.vdb` is committed), run in this
directory:

    make coverage

which runs `urg -dir {{__VCS_COVERAGE_DIR__}} -report coverage` and writes the
HTML/text report under `coverage/`. `urg` needs a coverage license
(e.g. `VC-COVERAGE`); without it the report step fails while the raw `.vdb` is
still valid.

To gate coverage inside pytest, run a short driver in a subprocess (so its exit
commits the `.vdb`), then call `urg` and parse the line-coverage percentage —
see `example/*/test_*_wave_coverage.py` for a working pattern.
